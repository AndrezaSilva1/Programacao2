# Projeto 2 - Programação de Aplicação Web

## Integrante

Andreza Pereira da Silva

## Tema

Um sistema de cadastro de livros para usuários do universo literário.

## Descrição

O projeto de programação de aplicação web utiliza Flask. No sistema o usuário realiza cadastro e gerenciamento de livros.

## Funcionalidades

- Cadastro dos usuários

- Login e logout

- Cadastra os livros

- Listar os livros

- Editar os livros

- Remover os livros

- Filtrar por gênero literário

- Utilizar os bancos de dados SQLite

- Controle de acesso com sessões
